# atlantic-submerso
 - submarino-comuns: todos os utilitários normalmente usados, como conversão JSON ou XML entre outros.
 - submarino-files: leitor e escritor de arquivos além de leitura de arquivos especiais como certificados.
 - submarino-http-client: modulo de requisição HTTP próprio.
 - submarino-fiscal: o cargo chefe do atlantic-suberso-submarino, motor fiscal para cálculo de impostos brasileiro.
